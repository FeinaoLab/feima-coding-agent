# 路线图

## v0.1（2026-11-08，已完成）

- 双循环 AgentLoop：内层工具链 + 插话，外层追加任务
- 状态机：`isStreaming` 唯一权威，`agent_settled` 前必须已 idle
- 并发安全：运行中提交自动降级为插话
- 工具：`read_file` `write_file` `edit_file` `list_dir` `glob` `grep` `bash`
- 安全：路径围栏、读写黑名单、环境变量白名单、命令策略、握手、错误脱敏
- 接入：CLI 交互 / `run --json` / RPC JSONL
- 测试：18 用例（策略 7 / 循环 7 / 执行 4）

## v0.2（2026-11-08，已完成）

- [x] 上下文压缩：超过 token 阈值时摘要早期消息，保留工具调用结构
  - 系统提示不折叠、切分点只落在 user、工具调用与结果成对、压缩无收益则放弃
  - 降级链：模型摘要 → 规则摘要 → 不压缩
- [x] 会话持久化：`~/.feima/sessions/*.jsonl`，`feima resume [id|last]` 续跑
  - append-only、残行跳过、标题与本地时间显示、恢复时重建系统提示
- [x] 上下文化与会话的可观测：`/context`、`compact` 事件、`doctor` 报告

范围外（原计划在 v0.2，实际推迟，避免与压缩/持久化混在一起验证）：

- [ ] 重试策略：429/5xx 指数退避，最多 3 次，且只在"未产生工具副作用"前重试
- [ ] 工具确认机制：写文件、执行命令前可要求人工确认（`--confirm`）
- [ ] 多模型配置：`~/.feima/config.json` 支持 `models` 数组与别名
- [ ] 冒烟脚本：固定仓库 + 固定任务，回归一次约 3 分钟

## v0.3（约 3 周）

- [ ] 真实隔离后端：Windows Job Object / Linux namespace，`--sandbox strict` 可用
- [ ] 命令白名单模式：只允许 `git/npm/node/python` 等常用命令的指定子命令
- [ ] 权限分级：读 / 写 / 执行 / 网络 四档，按项目配置
- [ ] 重试策略与工具确认（从 v0.2 顺延）
- [ ] 会话索引（超过数百个会话时再上，接口已收敛在 `SessionStore`）

## v0.4

- [ ] 飞链 RAG 接入：`search_knowledge` 工具，返回带引用的片段
- [ ] 项目记忆：`AGENTS.md` 自动载入系统提示词
- [ ] MCP 客户端：工具来自外部进程时强制逐次确认，默认关闭

## v1.0

- [ ] Electron 桌面端，复用 `feima rpc`，渲染层不碰引擎
- [ ] 差异视图、会话列表、多窗口（每窗口一个 RPC 子进程）
- [ ] 三平台安装包（未签名先行）

---

## 不做清单

以下需求主动拒绝，避免范围膨胀：

- 多 Agent 编排 / 自主长期运行
- 内置浏览器与网页抓取（用工具调用外部命令替代）
- 模型微调、推理框架
- 云端托管版本（v1.0 之前）
